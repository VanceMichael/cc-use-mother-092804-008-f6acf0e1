# 领域边界

协调铁路重点旅客、宠物托运、行李搬运和临时证明确认。

现有领域资料围绕以下边界组织：

- 旅客与同行关系
- 重点服务预约
- 宠物与行李托运
- 车站任务交接
- 取消和改签

## 受理与去重

- 受理锚点跨改签稳定：同一旅客的同一服务意图（宠物按 pet_id 细分）始终回到同一预约
- 同一请求号重复提交、或资料完全一致的重试，返回既有预约，不重复生成环节
- 车次、乘降/运输区间、物种与笼箱、行李件、资格类别、证明有效期等关键字段变化时，预约转入人工确认；批准后重排，驳回后维持原计划

## 资格与任务生成

- 重点旅客必须持有明确资格类别（老人、孕妇、辅助设备）；核验通过前不生成接力环节
- 核验通过后沿车次停站生成"进站接送 → 分段接力（每两个停站之间一段）→ 出站送达"
- 宠物链为"发运受理 → 逐段押运 → 到达交付"；单独出行必须登记到站接收人
- 行李链为"取件 → 逐段运输 → 送达"，各环节携带同一组件号
- 临时证明仅一个开具环节，窗口为有效期限与乘车时刻的交集

## 执行与交接

- 派工校验岗位与所属站点；交接必须在时间窗内、且前序环节已完成
- 交接件数必须与登记件数一致，否则中止且任务不完成
- 临时身份证明只能在有效期限内开具；过期未开具的环节自动失效

## 变更与取消

- 列车调整要求新车次覆盖原路线；只重排尚未完成的环节，已完成环节时刻与事实不变
- 取消只撤销尚未发生的环节；前序交接已完成的物件不得撤销后序，避免物件失控
- 全部撤销记为已取消，部分完成后撤销记为部分撤销，已完成交接永久保留

## 可追溯与最小知情

- 每次受理、核验、确认、派工、交接、撤销、过期都形成带序号、时间、操作人的事件
- 值班人员视图只含站点、时间窗、动作、件数等执行必需信息
- 管理者责任链还原每个环节的责任人、交接双方与全部事件

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。
