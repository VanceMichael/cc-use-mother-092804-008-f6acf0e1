# 领域边界

协调铁路重点旅客、宠物托运、行李搬运和临时证明确认。

领域资料与后端围绕以下边界组织：

- 旅客与同行关系
- 重点服务预约（资格核验后生成分段接力任务）
- 宠物与行李托运（宠物可单独车次，行李可跨站运输）
- 车站任务交接（现场交接留痕、件数守恒）
- 取消和改签（只撤销尚未发生的环节，已完成事实保留）
- 重复请求与关键字段变更（幂等返回，变化进入人工确认）
- 值班最小信息视图与管理责任链还原

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。种子数据中的车站、车次、时刻与人员均为虚构。

## 不变量

- 同一 `idempotency_key` 至多对应一个预约，任何并发下不重复受理
- 重点旅客任务只在资格核验通过后生成；类别变更后原核验结论失效
- 宠物必须通过物种、笼具尺寸、重量、指定车站与车次校验
- 行李必须守住每单件数、单件重量，交接对象集合与受理清单完全一致
- 临时身份证明在有效期内方可交付与使用
- 已完成（completed）的任务不可撤销、不可变更；改签规则校验失败时预约保持原状
